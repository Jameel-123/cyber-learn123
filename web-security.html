Page 1 - Introduction to Web Security

Web security focuses on protecting websites, web applications, and online services from attacks.

Because modern organisations rely heavily on web applications, web security is extremely important.

Weak web security may expose sensitive user information.

Page 2 - Authentication

Authentication verifies a user’s identity.

Common Authentication Methods

  • Usernames and passwords
  • Multi-factor authentication
  • Biometrics
  • Security tokens
Example: Username + Password + Verification Code

Page 3 - Authorisation

Authorisation controls what users can access after logging in.

  • Admin users
  • Standard users
  • Guest users
Incorrect permissions may expose sensitive systems.

Page 4 - Session Management

Session management keeps users logged in while navigating a website.

Poor session handling may allow attackers to hijack accounts.

Example: localStorage is used in this prototype to simulate login sessions.

Page 5 - Input Validation

Input validation checks user input before processing it.

Validation helps reduce malicious input attacks.

  • Checking input length
  • Removing dangerous characters
  • Restricting invalid input types

Page 6 - SQL Injection and XSS

SQL Injection

SQL Injection attacks manipulate database queries.

Poorly validated input increases SQL Injection risk.

Cross-Site Scripting (XSS)

XSS injects malicious scripts into web pages.

  • Steal session data
  • Redirect users
  • Modify page content

Page 7 - HTTPS and Encryption

HTTPS encrypts communication between users and websites.

HTTP = Unencrypted HTTPS = Encrypted

Encryption protects passwords and personal information.
