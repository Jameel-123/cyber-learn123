Networking Basics

Networking is one of the most important foundations in cybersecurity. Security professionals must understand how devices communicate in order to identify threats, analyse traffic, and protect systems.

IP Addresses

An IP address identifies a device on a network. Devices use IP addresses to communicate with each other.

There are two main types of IP addresses:

  • IPv4
  • IPv6
IPv4 Example: 192.168.1.10
IPv6 Example: 2001:0db8:85a3::8a2e:0370:7334

Public and Private IP Addresses

Public IP

A public IP address is accessible over the internet. It identifies a network externally.

Private IP

Private IP addresses are used inside local networks such as homes, schools, and businesses.

Common private IP ranges: 192.168.x.x 10.x.x.x 172.16.x.x - 172.31.x.x

Ports

Ports are communication endpoints used by services and applications. Open ports help identify what services are running on a system.

Common Ports

  • 21 - FTP
  • 22 - SSH
  • 25 - SMTP
  • 53 - DNS
  • 80 - HTTP
  • 443 - HTTPS

Protocols

Protocols are rules that define how data is transmitted across networks.

HTTP and HTTPS

HTTP is used for website communication. HTTPS is the secure encrypted version.

DNS

DNS converts domain names into IP addresses.

Example: google.com → 142.250.179.14

SSH

SSH allows secure remote access to systems.

Firewalls

Firewalls help protect networks by filtering incoming and outgoing traffic.

Firewalls can block suspicious traffic and reduce exposure to attacks.

Network Scanning

Security professionals use scanning tools to identify active hosts, open ports, and running services.

Example Command: nmap -sV 192.168.1.10

This command scans a target system and attempts to identify running services and versions.
