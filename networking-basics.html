Page 1 - Introduction to Networking

Networking allows devices to communicate and exchange data. Understanding networking is extremely important in cybersecurity.

Security professionals use networking knowledge to:

  • Analyse traffic
  • Identify threats
  • Secure systems
  • Monitor communication
Example: Computers communicate using networks and protocols.

Page 2 - IP Addresses

An IP address identifies a device on a network.

IPv4

Example: 192.168.1.10

IPv6

Example: 2001:0db8:85a3::8a2e:0370:7334

Devices use IP addresses to send and receive information.

Page 3 - Public and Private IP Addresses

Public IP

Public IP addresses are accessible over the internet.

Private IP

Private IP addresses are used inside local networks.

Common Private Ranges: 192.168.x.x 10.x.x.x 172.16.x.x - 172.31.x.x

Page 4 - Ports and Services

Ports are communication endpoints used by services.

Common Ports

  • 21 - FTP
  • 22 - SSH
  • 53 - DNS
  • 80 - HTTP
  • 443 - HTTPS
Open ports may expose services to attackers.

Page 5 - Protocols

Protocols define how devices communicate.

HTTP and HTTPS

HTTPS is the secure encrypted version of HTTP.

DNS

DNS converts domain names into IP addresses.

google.com → 142.250.179.14

SSH

SSH allows secure remote access to systems.

Page 6 - Network Scanning

Security professionals scan systems to identify:

  • Open ports
  • Running services
  • Active devices
  • Potential weaknesses
Example: nmap -sV 192.168.1.10
