Defensive Security

Defensive security focuses on protecting systems, networks, applications, and users from cyber threats and attacks.

Defensive teams work to prevent attacks, detect suspicious activity, and respond to security incidents quickly and effectively.

Firewalls

Firewalls filter incoming and outgoing network traffic. They help block unauthorised access and reduce exposure to threats.

Firewalls can:

  • Allow trusted traffic
  • Block suspicious traffic
  • Monitor connections
  • Restrict exposed services

Antivirus and Endpoint Protection

Antivirus software helps detect and remove malicious software from systems and devices.

Modern endpoint protection tools may also monitor behaviour, detect suspicious activity, and isolate infected devices.

Patching

Patching means applying updates to software, applications, and operating systems.

Updates often fix vulnerabilities that attackers could exploit.

Outdated systems may contain known vulnerabilities that are publicly documented.

Logging and Monitoring

Logging records activity that occurs on systems and networks.

Monitoring helps security teams identify suspicious behaviour, failed logins, malware activity, or unusual traffic patterns.

Example Log Entry: Failed Login Attempt Username: admin Time: 14:22

IDS and IPS

Intrusion Detection System (IDS)

IDS tools monitor traffic and generate alerts when suspicious behaviour is detected.

Intrusion Prevention System (IPS)

IPS systems can actively block suspicious traffic before it reaches a target.

Backups

Backups help organisations recover data after accidental deletion, hardware failure, or cyber attacks.

Backups should be:

  • Regularly tested
  • Stored securely
  • Protected from ransomware

Incident Response

Incident response is the process of handling security incidents and recovering from attacks.

Incident response usually includes:

  1. Preparation
  2. Detection
  3. Containment
  4. Eradication
  5. Recovery
  6. Lessons Learned

Security Awareness

Human error is a major cause of security incidents.

Security awareness training helps users recognise:

  • Phishing emails
  • Suspicious links
  • Unsafe downloads
  • Password risks
