Page 1 - Introduction to Defensive Security

Defensive security focuses on protecting systems, networks, applications, and users from cyber attacks.

Security teams work to:

  • Prevent attacks
  • Detect suspicious activity
  • Respond to incidents
  • Protect sensitive information
Defensive security reduces risk exposure and improves organisational protection.

Page 2 - Firewalls

Firewalls filter incoming and outgoing network traffic.

Firewalls help:

  • Block suspicious traffic
  • Allow trusted communication
  • Restrict exposed services
  • Monitor connections
Example: Firewall blocks unauthorised remote access.

Page 3 - Antivirus and Endpoint Protection

Antivirus software detects and removes malware.

Modern endpoint protection systems may:

  • Monitor suspicious behaviour
  • Block malicious files
  • Isolate infected devices
  • Alert security teams

Page 4 - Patching

Patching means applying updates to software and operating systems.

Outdated systems may contain publicly known vulnerabilities.

Regular patching reduces security risks and improves protection.

Page 5 - Logging and Monitoring

Logging records activity on systems and networks.

Monitoring helps identify suspicious behaviour.

Example Log Entry: Failed Login Attempt Username: admin Time: 14:22

Page 6 - IDS and IPS

Intrusion Detection System (IDS)

IDS tools monitor traffic and generate alerts.

Intrusion Prevention System (IPS)

IPS tools can actively block suspicious activity.

Page 7 - Backups and Incident Response

Backups

Backups help organisations recover data after attacks or failures.

Page 8 - Security Awareness

Human error is a major cause of security incidents.

Security awareness training helps users recognise:

  • Phishing emails
  • Suspicious links
  • Password risks
  • Unsafe downloads
