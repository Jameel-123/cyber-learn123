Page 1 - Introduction to Cybersecurity Terms

Cybersecurity contains many technical terms and concepts. Understanding these terms helps users understand reports, tools, and security discussions more effectively.

Understanding terminology is essential for cybersecurity learning and communication.

Page 2 - Vulnerabilities and Exploits

Vulnerability

A vulnerability is a weakness in a system, application, or configuration.

Exploit

An exploit is a technique used to take advantage of a vulnerability.

Vulnerability → Exploit → Security Risk

Page 3 - Threats and Risks

Threat

A threat is anything capable of causing harm to systems or organisations.

Risk

Risk measures the likelihood and impact of a threat affecting a system.

Organisations reduce risk through security controls.

Page 4 - Authentication and Authorisation

Authentication

Authentication verifies a user’s identity.

Authorisation

Authorisation controls what users can access.

Authentication = Who are you? Authorisation = What can you access?

Page 5 - Malware and Phishing

Malware

Malware is malicious software designed to damage or disrupt systems.

  • Viruses
  • Ransomware
  • Spyware

Phishing

Phishing attacks trick users into revealing sensitive information.

Page 6 - Encryption and Firewalls

Encryption

Encryption protects data by converting it into unreadable format.

Firewall

Firewalls filter network traffic entering or leaving systems.

HTTPS uses encryption to secure communication.

Page 7 - Reconnaissance and Enumeration

Reconnaissance

Reconnaissance gathers information about a target environment.

Enumeration

Enumeration collects detailed information from systems and services.

Example: nmap -sV 192.168.1.10

Page 8 - Incident Response and Remediation

Incident Response

Incident response handles security incidents and recovery activities.

Remediation

Remediation fixes vulnerabilities and reduces risk exposure.

Page 9 - Common Security Tools

Nmap

Network scanning tool used to identify hosts and services.

Example: nmap -sV 192.168.1.10

Wireshark

Packet analysis tool used to inspect network traffic.

Burp Suite

Web application testing tool.

Metasploit

Penetration testing and security research framework.
