Cybersecurity Key Terms

Cybersecurity contains many technical terms and concepts. Understanding this terminology helps users communicate clearly, understand reports, and interpret technical information.

Important Terms

Vulnerability

A weakness in a system, application, or configuration that could potentially be exploited.

Exploit

A method or technique used to take advantage of a vulnerability.

Threat

Anything capable of causing harm to a system or organisation.

Risk

The likelihood and impact of a threat affecting a system.

Patch

An update released to fix bugs or security vulnerabilities.

Firewall

A security control that filters network traffic entering or leaving a system.

Malware

Malicious software designed to damage systems, steal information, or disrupt services.

Phishing

A social engineering attack that tricks users into revealing sensitive information.

Reconnaissance

The process of gathering information about a target environment.

Enumeration

Collecting detailed information from systems and services.

Authentication

Verifying a user’s identity before granting access.

Authorisation

Defining what actions or resources a user can access.

Encryption

Transforming data into unreadable form to protect confidentiality.

Incident Response

The process of responding to and recovering from security incidents.

Remediation

The process of fixing vulnerabilities or reducing risk.

Common Security Tools

Nmap

A network scanning tool used to identify hosts, ports, and services.

Example: nmap -sV 192.168.1.10

Wireshark

A packet analysis tool used to inspect network traffic.

Burp Suite

A web application testing tool commonly used during penetration testing.

Metasploit

A framework used for penetration testing and security research.
