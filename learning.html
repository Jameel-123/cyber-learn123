Cybersecurity Basics

What is cybersecurity?

Cybersecurity is the practice of protecting computers, networks, applications, and data from unauthorised access, attack, damage, or misuse.

The CIA Triad

The CIA Triad is a core security model that explains three important security goals:

  • Confidentiality: Keeping information private.
  • Integrity: Making sure information is accurate and unchanged.
  • Availability: Making sure systems and data are accessible when needed.

Why cybersecurity matters

Cybersecurity helps protect personal information, business systems, financial data, and critical services. Weak security can lead to data breaches, system downtime, identity theft, and financial loss.

Networking Basics

Networking is one of the most important foundations in cybersecurity. Understanding how devices communicate helps users understand scanning, monitoring, and security risks.

IP Addresses

An IP address identifies a device on a network. Devices use IP addresses to send and receive data.

Example IP Address: 192.168.1.10

Ports

Ports are communication endpoints used by services. A system may have many ports, and open ports can show which services are running.

  • Port 22: SSH
  • Port 80: HTTP
  • Port 443: HTTPS
  • Port 53: DNS

Protocols

Protocols are rules for communication. Examples include HTTP, HTTPS, DNS, FTP, and SSH. Understanding protocols helps explain how data travels across networks.

Penetration Testing Lifecycle

1. Planning and Scope

Before testing begins, the tester must understand what systems are allowed to be tested. This is known as scope. Testing outside scope can be unauthorised.

2. Reconnaissance

Reconnaissance means gathering information about the target environment. This can include domain names, IP addresses, services, and public information.

3. Scanning

Scanning is used to identify active hosts, open ports, and running services. This helps understand what is exposed.

Example scan command: nmap -sV 192.168.1.10

4. Analysis

After scanning, results are reviewed to identify potential weaknesses, misconfigurations, or risky services.

5. Reporting

Findings should be documented clearly, including risk level, evidence, and recommended fixes.

Web Security Basics

Authentication

Authentication is the process of proving a user’s identity, usually through a username and password.

Authorisation

Authorisation controls what a user is allowed to access after logging in. For example, an admin user may have more privileges than a normal user.

Input Validation

Input validation checks user input before it is processed. This helps prevent invalid or harmful data from affecting the application.

Session Management

Session management keeps users logged in while they move between pages. In this prototype, localStorage is used to simulate session handling.

Defensive Security

Firewalls

A firewall filters network traffic and helps control what is allowed in or out of a network.

Logging

Logs record events that happen on systems. They are useful for investigating incidents and understanding suspicious activity.

Patching

Patching means applying updates to fix bugs or security vulnerabilities. Keeping software updated reduces risk.

Backups

Backups allow data to be restored after accidental deletion, system failure, or cyber incidents.

Key Terms

  • Vulnerability: A weakness that could be exploited.
  • Exploit: A method used to take advantage of a weakness.
  • Risk: The chance and impact of something going wrong.
  • Patch: An update used to fix a security issue.
  • Firewall: A control that filters network traffic.
  • Reconnaissance: Gathering information about a target.
  • Enumeration: Collecting detailed information from services.
  • Remediation: Fixing or reducing a security weakness.
