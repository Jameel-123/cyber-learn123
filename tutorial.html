Cybersecurity Toolkit Tutorial

This tutorial explains how the Cybersecurity Toolkit works, how each module functions, and what the generated results mean.

The toolkit has been designed for educational and authorised cybersecurity testing purposes only.

Step 1 - Download and Open the Tool

Download the toolkit from the Download page, extract the ZIP folder, and open the project inside Visual Studio Code.

File → Open Folder

Once opened, press the Run button to launch the application window.

Port Scanner

The Port Scanner checks whether ports are open on a target system.

Open ports may indicate active services that could potentially be exposed.

Main Function

def scan_ports(host, ports_text):

Port Check Logic

result = s.connect_ex((host, port))

If the connection succeeds, the port is considered open.

Open ports may reveal services that attackers could target.

Service Checker

The Service Checker identifies common services associated with port numbers.

Example Services

  • 21 → FTP
  • 22 → SSH
  • 80 → HTTP
  • 443 → HTTPS

The module compares port numbers against a predefined service dictionary.

File Hasher

The File Hasher generates cryptographic hash values for selected files.

Hashing helps verify:

  • File integrity
  • Whether files were modified
  • Evidence consistency

Main Function

def hash_file(file_path, algorithm="sha256"):

Hash Generation

hash_object.update(chunk)

The tool reads file data in chunks and generates a SHA-256 hash value.

Report Generation

Generated scan reports are stored locally inside the reports folder.

reports/report_88_20260524_211612.json

Reports may contain:

  • Open ports
  • Detected services
  • Banner information
  • Generated hashes

Report Upload System

The Upload Report interface demonstrates how reports could be uploaded to a future backend platform.

Users can:

  • Select report files
  • Enter API keys
  • Simulate uploads
The current website uses GitHub Pages and does not include backend storage. Reports are not permanently uploaded online.
