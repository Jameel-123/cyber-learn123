Step 1 - Download the Tool

Download the Cybersecurity Toolkit from the Download Tool page.

The toolkit contains several educational cybersecurity modules designed to demonstrate scanning, service analysis, hashing, and reporting workflows.

Step 2 - Open the Project

Extract the ZIP folder and open the project inside Visual Studio Code.

File → Open Folder

Once the project is open, all toolkit files and modules will be visible inside the editor.

Step 3 - Run the Application

Press the Run button inside Visual Studio Code to launch the graphical user interface.

Run → Start Debugging

After launching, the Cybersecurity Toolkit window will open.

Step 4 - Port Scanner

The Port Scanner checks systems for open ports.

  • Identifies open ports
  • Detects exposed services
  • Supports reconnaissance activities
Open ports may expose services to potential attackers.

Step 5 - Service Checker

The Service Checker verifies whether network services are active and accessible.

  • Checks availability
  • Reviews active services
  • Helps understand exposure

Step 6 - Banner Grabber

The Banner Grabber retrieves available banner information from services.

  • Software names
  • Version information
  • Potential operating system details
Exposed banners may reveal useful reconnaissance information.

Step 7 - Process Viewer

The Process Viewer displays running processes on the local machine.

  • Shows active applications
  • Displays background services
  • Helps identify suspicious activity

Step 8 - File Hasher

The File Hasher generates hash values for selected files.

  • Checks file integrity
  • Detects file modification
  • Supports digital evidence handling
Example MD5 Hash: 5f4dcc3b5aa765d61d8327deb882cf99

Step 9 - Report Viewer

The Report Viewer allows users to open and review generated reports.

  • Displays scan findings
  • Shows output information
  • Reviews saved results

Step 10 - Upload Report

The Upload Report feature demonstrates how reports could be uploaded to a future backend platform.

  • Select report files
  • Enter API keys
  • Simulate uploads
Reports are not permanently uploaded online. The current system is a frontend prototype only.

Step 11 - Report Storage

Generated reports are saved locally inside the reports folder.
